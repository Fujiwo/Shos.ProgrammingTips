| これまでの書き方と課題 | C++03 では、`std::vector` を別の変数やコンテナーに渡すと、要素がすべてコピーされた。値で返すときは、戻り値の最適化 (RVO・NRVO) でコピーが省かれることが多かったが、保証はなく、省略されないとき(複数のローカル変数を条件で返し分けるなど)は要素がすべてコピーされた。確実にコピーを避けるため、出力引数 (`void LoadLines(std::vector<std::string>& lines)`) や `swap` を使う書き方があったが、読みにくい | |

| ムーブを使うメリット | `std::vector` のアロケーターを別途指定しないムーブ構築は、要素数によらず定数時間。ムーブ一般の計算量は型と操作による。コピーの省略に頼らなくても、値で返したときに要素がコピーされないので、出力引数を使わず、値で返す素直な書き方ができる(連載全体の計画書 4節)。コピーできない型(`std::unique_ptr`、`std::thread`、`std::fstream` など)も、ムーブなら持ち主を移せる。`std::move` がコードに残るので、中身を引き取ってよいという意図が読み手に分かる | メリット |

## 3. コード例

すべて `main.cpp` に、例ごとの関数として置き、`main` から順に呼ぶ。題材は「文書の行の一覧 (`std::vector<std::string>`)」で統一する。データの準備は `MakeLines` に分け、記事では省く。

| 例 | キャプション案 | 内容 |
|---|---|---|
| 例 1. | 「ムーブすると、配列を複製せずに引き継ぐ」 | `std::vector<std::string>` をコピーした場合と、`std::move` でムーブした場合で、`data()` が元と同じ配列を指すかを出力する。コピーは別の配列、ムーブは同じ配列になる |
| 例 2. | 「関数から、値で返す」 | `std::vector<std::string> LoadLines()` のように値で返す。C++03 の出力引数の書き方と並べ、呼ぶ側が素直に書けることを示す |
| 例 3. | 「コンテナーに、ムーブで入れる」 | 組み立てた `std::string` を `lines.push_back(std::move(line))` で入れる。`line` はこのあと使わないことをコメントで示す |
| 例 4. | 「値で受け取り、メンバーにムーブする」 | `class Document` のコンストラクターで、`std::vector<std::string> lines` を値で受け取り、`lines_(std::move(lines))` で移す。呼ぶ側が変数を渡せばコピー1回、`std::move(変数)` を渡せばコピーなしになることを、渡す前の変数の `data()` と、メンバーの `data()` の比較で示す。一時オブジェクト(`MakeLines()` の戻り値など)を直接渡すと比べる元のアドレスがないので、出力では比べず、`std::move` を付けた場合と同じくコピーされないことをコメントと地の文で述べる |

- 例 1 が、この記事の要。ムーブで何が起きるかを、出力で見せる。
- `data()` の比較は、`std::vector` のムーブコンストラクターが元の配列を引き継ぐことを前提にしている。C++11 の規格の文言(コンテナーの要件の表で、ムーブ構築が定数時間であること)と、規格でどこまで保証されているかを、執筆時に確かめる。保証の根拠を示せない場合は、「主な実装では」と書くか、例 1 を別の見せ方にする。
- `std::string` ではなく `std::vector` の `data()` を比べるのは、`std::string` の短い文字列は SSO によってムーブでも複製されるため(連載全体の計画書 4節)。
- ムーブ元の値(`size()` など)は出力しない。
- `return std::move(local);` の注意は、地の文で説明する。コード例にはしない。

## 4. 扱わないこと

- 右辺値参照と `std::move` の正体(記事 1)。この記事では、「`std::move` は引数を右辺値として扱うキャストで、それ自体はムーブしない。実際に中身を引き取るかは、渡した先の処理による」と述べ、記事 1 へのリンクを添える(連載全体の計画書 7節)
- ムーブコンストラクターの書き方(記事 3)
- C++17 のコピー省略の保証の詳細。事実を1文で述べる程度にする
- `std::unique_ptr` の詳しい使い方。コピーできない型の例として名前を出す程度にする
- `emplace_back`(記事 4 で、完全転送の使用例として触れる)
- 処理時間のベンチマーク(環境で数字がぶれるため)
