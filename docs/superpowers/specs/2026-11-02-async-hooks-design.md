# 非同期フックの設計

## 目的

ファイル編集後に実行されるフックの完了待ちをなくし、編集時の待ち時間を減らす。

## 変更内容

`.claude/settings.json` の `PostToolUse` に登録されている次の3つのコマンドに、それぞれ `"async": true` を設定する。

- Copilot 指示ファイルの同期
- スキルファイルの同期
- 記事目次の更新

各コマンド、タイムアウト、ステータスメッセージは変更しない。

## 挙動と確認

フックはバックグラウンドで実行されるため、編集操作はフックの完了を待たずに戻る。編集直後は生成先が更新中の場合がある。設定が有効な JSON であり、3つすべてに `async: true` が設定されていることを確認する。

## 対象外

フックスクリプトの処理内容や実行頻度、エラー処理は変更しない。
