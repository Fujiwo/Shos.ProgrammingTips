# Markdown Quality Audit Checklist

自動検査 (`scripts/check_markdown.py`) の前後に、このチェックリストで確認する。

## 自動検査で確認する項目

- 相対リンクと画像のリンク切れ
- 閉じていないコードフェンス
- 長すぎるコードブロック
- (オプション) コードフェンスの直前の言語ラベル
- (オプション) Mermaid の使用
- (オプション) Markdown の脚注記法 (`[^1]`)

オプションの検査は、プロジェクトの書式ルールがそれを定めているときだけ有効にする。

## 目視で確認する項目

- 対象範囲が正しいこと。
- 執筆プロファイルや指示ファイルが定める書式 (画像の置き場所、バナー、コード例の前提やキャプションの形式、サンプルコードの置き場所など) を満たしていること。
- 外部リンクのテキストが、実際のページタイトルになっていること。

## 重大度の目安

- Blocking: リンク切れ、ファイルの欠落、閉じていないコードフェンス
- Important: プロジェクトの書式ルールへの違反 (言語ラベルの欠落、禁止された記法の使用、必須要素の欠落など)
- Minor: 公開を妨げない読みやすさの問題 (長いコードブロックなど)

## 報告の形

1. 検査した範囲
2. 全体の結果
3. Blocking の所見
4. Important の所見
5. Minor の所見
6. 次にやること
