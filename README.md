# Shos.ProgrammingTips

プログラミングに関する Tips の記事と、そのサンプルコードです。C#・C++・JavaScript などの、最近の数バージョンの新機能の使用例を、1本の記事で一つずつ紹介します。

## 記事

記事の一覧は、[目次](Articles/README.md) にあります。

## フォルダーの構成

| フォルダー | 内容 |
|---|---|
| `Articles/<言語>/` | 記事 (Markdown) |
| `Articles/<言語>/Sources/` | 記事のサンプルコード。言語ごとのソリューション (JavaScript はフォルダー) に、記事ごとのプロジェクトがある |
| `Plans/` | 記事の計画書 |
| `Reviews/` | 記事やリポジトリのレビュー結果 |
| `Tools/` | 記事とサンプルコードを検査するスクリプト |

記事の書き方とリポジトリの約束事は、[CLAUDE.md](CLAUDE.md) と [執筆プロファイル.md](執筆プロファイル.md) にあります。
